# Agent Skills

An overview of the available skills that help AI coding agents work with TSTyche.

## What’s Included

The collection of skills covers:

- writing, reviewing, migrating, and debugging type tests
- installing, configuring, and troubleshooting TSTyche projects
- using custom reporters and the programmatic API

## Install

To install the skills, run:

```shell
npx skills add tstyche/tstyche-skills​
```

<Note>

See the [tstyche/tstyche-skills](https://github.com/tstyche/tstyche-skills) repository for more installation options and detailed guidance.

</Note>
