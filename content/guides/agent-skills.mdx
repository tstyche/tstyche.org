# Agent Skills

TSTyche Agent Skills help AI coding agents work with TSTyche. The collection includes skills for:

- Writing, reviewing, migrating, and debugging type tests.
- Installing, configuring, and troubleshooting TSTyche projects.
- Using the programmatic API, including runners and reporters.

See the [tstyche/tstyche-skills repository](https://github.com/tstyche/tstyche-skills) for the skills, installation instructions, and detailed guidance.
