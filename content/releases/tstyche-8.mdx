### Requirements

<Warning>

**Breaking!** The minimum supported Node.js version is `24.11`. It is recommended to use the latest [LTS release](https://nodejs.org/en/about/previous-releases).

</Warning>

### Environment Variables

<Warning>

**Breaking!** The `TSTYCHE_TIMEOUT` environment variable is removed. Use [`TSTYCHE_FETCH_TIMEOUT`](#fetch-timeout) instead.

</Warning>

<Warning>

**Breaking!** The `TSTYCHE_TYPESCRIPT_MODULE` environment variable is removed. Use [`TSTYCHE_TYPESCRIPT_SPECIFIER`](#typescript-specifier) instead.

</Warning>

#### `TSTYCHE_FETCH_TIMEOUT` [#fetch-timeout]

`TSTYCHE_FETCH_TIMEOUT` is the new name of `TSTYCHE_TIMEOUT`. The default value is increased from 30 to 60 seconds, and to 180 seconds in continuous integration environments.

#### `TSTYCHE_TYPESCRIPT_SPECIFIER` [#typescript-specifier]

`TSTYCHE_TYPESCRIPT_SPECIFIER` is the new name of `TSTYCHE_TYPESCRIPT_MODULE`.

### Programmatic Usage

<Warning>

**Breaking!** The `tstyche/api` entry point requires the `typescript` and `@typescript/typescript6` packages to be installed as development dependencies.

</Warning>
